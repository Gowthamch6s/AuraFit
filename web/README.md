# AuraFit Dashboard — Phase 6

React 18 + TypeScript + Vite dashboard built on the exact Phase 5 FastAPI contracts.

## Run

Prerequisites: Node.js 20+, npm, and optionally the running Phase 5 FastAPI service.

```bash
cd web
npm install
npm run dev
```

Open http://127.0.0.1:5173 . It opens in **Demo mode** with clearly labeled synthetic data. Click **Settings & connection** to connect a bearer token generated by the Phase 4 key CLI. Start the API on http://127.0.0.1:8000; Vite proxies the API routes (see `vite.config.ts`). The token is held only in React memory and disappears when you refresh or disconnect. Do not deploy a permanent browser bearer token solution without a production identity and session model.

## Data-contract behaviors

- Assessment: `GET /metrics/allostatic-load`, object property `assessment`.
- Targets: `GET /targets/adaptive`, object property `targets`.
- Forecast: `GET /predictions/next-day`, objects with `predicted_recovery_score` nullable. Never invent a forecast.
- Trends: seven historical `GET /metrics/allostatic-load?local_date=YYYY-MM-DD` requests. A 404, 409, or 422 response skips that date; other failures propagate.
- Conversation: `POST /agent/chat/stream` SSE with fallback to `POST /agent/chat`.
- Real-time intraday energy budget is **not** available in the Phase 5 backend. No fake hourly target or calorie prescription is rendered.
- Demo chart and metric readings are intentionally illustrative, not user records.

## Production notes

Deploy UI and API behind the same-origin HTTPS reverse proxy or an authenticated backend-for-frontend; require rate limiting, CSRF defenses for session-based auth, CSP, log scrubbing, external security review, and end-to-end database integration tests. Ensure domain-specific health privacy and regulatory assessment prior to user deployment.
